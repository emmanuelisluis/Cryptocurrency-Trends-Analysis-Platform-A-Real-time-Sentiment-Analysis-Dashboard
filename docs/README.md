# Crypto Dashboard Documentation

Welcome to the documentation for the Crypto Dashboard application. This project aims to provide advanced market analysis tools, with a strong focus on Order Flow Analysis (OFA) and the integration of Machine Learning (ML) insights to augment traditional trading indicators.

The dashboard visualizes detailed market data, including order book depth, time and sales, footprint charts, volume profiles, and various delta-based metrics. Furthermore, it incorporates (simulated) ML predictions for phenomena like momentum sustainability, breakout viability, and absorption event outcomes, directly overlaid or accessible from relevant chart components.
