# Crypto Dashboard

This project is a cryptocurrency dashboard that displays real-time data and historical trends for various cryptocurrencies. It features a Python backend with FastAPI and a React/TypeScript frontend.

## Features

*   Real-time price updates
*   Historical price charts
*   User authentication
*   Portfolio tracking
*   Customizable dashboard

## Technologies

*   **Backend:** Python, FastAPI, TimescaleDB
*   **Frontend:** React, TypeScript, Chart.js
*   **Data Sources:** Binance API, KuCoin API
